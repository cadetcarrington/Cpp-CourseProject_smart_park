# Plate recognition examples

This folder contains 40 unmodified CCPD full-frame photographs: 20 blue plates from CCPD2019 `ccpd_base` and 20 green plates from CCPD2020 `ccpd_green/val`. These are integration examples, not a representative benchmark. The expected plate is decoded from the original CCPD filename, not from model output. The complete per-image provenance, validation split, resolution and SHA-256 are in [manifest.csv](manifest.csv). Some images are intentionally difficult: for example, the current two-model pipeline reads `green-01.jpg` as `皖AD095261` rather than its annotated `皖AD09528`, with detection confidence about 0.40. Review the image and model result instead of treating all labels as verified predictions.

The original four examples remain unchanged. The other 36 were selected reproducibly: from each local recognition-validation manifest (`model/datasets/ccpd_rec/val.txt` for blue, `model/datasets/ccpd_rec/val_green.txt` for green), keep entries whose full-frame symlink resolves to the corresponding CCPD source pool, exclude the original four, sort by SHA-256 of the UTF-8 bytes `smartpark-examples-v1:` plus the generated validation filename, and take the first 18 per pool. `scripts/curate_plate_examples.py --check` verifies the images and manifest against the local datasets; generating the folder requires Pillow and the original datasets.

CCPD2019 includes an MIT license and copyright notice, retained in [CCPD2019-LICENSE](CCPD2019-LICENSE). Please cite *Towards End-to-End License Plate Detection and Recognition: A Large Dataset and Baseline* when using CCPD2019. The green images originate from CCPD2020; the project owner confirmed permission to redistribute the selected green samples, but no upstream license text was available locally, so no specific license is asserted for them.

These research-dataset images contain legible license plates. They are not anonymized or independently consent-verified. Do not add privately collected camera imagery without a separate privacy and rights review.
