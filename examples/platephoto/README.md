# 车牌照片留档（车辆入库 / 出库）

macOS 管理端做「识别并入场」「识别并出场」时，会把识别用的车牌裁剪图复制到这里
（`PlatePhotoArchive` 负责）。目录是运行时自动创建的，照片本身不入库。

## 目录与命名

```
examples/platephoto/
├── 皖AD12368_20261018-101500.jpg               # 在场车辆：<车牌>_<入库时间>.jpg
├── 皖AD12368_20261018-101532.jpg               # 同一秒重复归档时加 _1、_2 后缀
└── history/
    ├── 皖AD12368_20261018-101500_20261018-120000.jpg    # 入场那张
    └── 皖AD12368_20261018-101500_20261018-120000_2.jpg  # 出库那张（同一趟停车）
```

- 车辆还在场时，照片放在本目录根下，文件名是「车牌 + 入库时间」。
- 车辆出库办完后，这次停车的照片会挪进 `history/`，并改名为
  「车牌 + 入库时间 + 出库时间」；同一趟停车有多张（入场、出库各一张）时，
  按时间先后加 `_2`、`_3` 后缀，第一张就是入场那张。
- 手工输入车牌入场没有照片，出库时也就不会生成 history 记录。
- 时间都是本机时区的 `yyyyMMdd-HHmmss`。

## 位置是怎么定的

管理端在构建目录里运行，不能写死相对路径，所以 `PlatePhotoArchive` 会从可执行文件
所在目录逐级向上找「同时含 `CMakeLists.txt` 和 `examples/plates`」的目录当作仓库根，
照片就放进 `<仓库根>/examples/platephoto`。找不到（例如把 app 复制到 `/Applications`）
时退回 `~/Library/Application Support/smartpark/plate-photos/`，功能不变。
测试或部署可用环境变量 `SMARTPARK_PLATE_PHOTO_DIR` 指定别的目录。

结果面板底部会显示当前照片的实际路径，点「在访达中显示」即可打开所在目录。
