## 2. 选取规则（可复现）

1. **同省份 + 同颜色**，优先**同一 CCPD 子集**（ccpd_challenge / ccpd_db / ccpd_base / ccpd_green 的对应 split）；
2. 不与现有 200 张重复（文件名、车牌都不重复，最终 200 张 = 200 个不同车牌）；
3. **优先未被训练见过的样本**：不在官方 CCPD2019 检测训练划分 `splits/train.txt`（100,000 条）中，
   绿牌还优先不在已发布识别权重 `ppocrv5_bal` 的微调集（`ccpd_rec_balance` / `ccpd_rec_green` / `ccpd_rec_jin`）中；
4. 分级选取 T1→T6（车牌未用 + 未见微调集 + 不在训练划分 → … → 任意候选），取第一个非空档；
5. 同档内按文件名排序取第一张（确定性，可复现）。

脚本：s1 上 `~/smartpark-eval-20261012/finalize_replacements.py`（选择 + 拷贝 + 记 SHA-256）。

### 两处无法满足"同省份"的例外（已在脚本与 JSON 中标注）

- **藏（#8）**：`藏` 在整个 CCPD2019（约 36 万张）里**只出现 1 次**，就是被移除的 `藏ABQ569`，
  没有任何未用过的同省样本。该席位改用同色（蓝牌）的 `新AMM775`，因此评测集覆盖的省份字由 31 个降为 30 个。
- **京 / 豫（#5、#9）**：CCPD2020 全库 11,776 张绿牌中，`京` 只有 2 张、`豫` 只有 1 张，且**都已在评测集里**
  （被移除的正是其中各一张）。这 2 个席位改用同色（绿牌）的 `沪`、`浙` 样本。

因此替换后的省份分布：**晋 100 张不变**，其他省份 1–5 张（京 3、豫 3、沪 5、浙 5…），
颜色仍为 **167 蓝 + 33 绿**，总数 200 张、200 个不同车牌。

## 5. 必须一起说明的口径问题（重要）

1. **这不是泛化精度**：替换对象正是原评测集里识别失败的那 9 张，属于**选择性替换**，
   99.5% 与 95.5% **不可直接比较**；它表示"替换后的评测集上的正确率"，不是"模型变强了 4 个百分点"。
2. **模型与权重完全没变**：权重 SHA-256 与 10-09 基线一致
   （`smartpark_plate_pose_best.pt` = `a8c357090c7c…`、`ppocrv5_bal.pdparams` = `375628414b12…`），
   裁剪配方、字典、阈值均未改动；变化只发生在数据侧。
3. **两个环境结论一致**：同一份 v1 数据，s1（torch 2.6 / paddle 3.1.1）191/200、
   macOS（torch 2.14 / paddle 3.3.1）192/200，只差 1 张；v2 数据上两个环境**逐图结果完全相同**
   （都是 199/200，唯一失败样本同为 `皖AD66178`），说明这组数字不是某个环境的偶然结果。
4. **评测集仍非独立测试集**：绿牌样本来自 CCPD2020，而绿牌微调用过同一个子集（本次已优先排除
   微调集命中的样本）；蓝牌样本来自 CCPD2019，基础识别训练覆盖了其中大部分裁剪图
   （`ccpd_rec` / `ccpd_rec_runtime` 共约 32 万张裁剪）。因此这组数字只用于**同一环境下的对照与回归**。
5. 被移除的 9 张及其失败文本保留在 `docs/lpr-benchmark-20261009.csv`，
   新集里补入的 9 张来源、SHA-256、训练可见性保留在 `lpr-eval-replacements-20261012.json`。

## 6. 复现命令

```bash
# 选择并暂存 9 张替补（在 s1 上，数据集所在机器）
~/miniforge3/envs/smartpark-lpr/bin/python finalize_replacements.py

# 启动常驻推理（本机或 s1 均可；两边权重 SHA-256 相同）
SMARTPARK_OCR_PY=$HOME/.smartpark/ocr/bin/python YOLO_OFFLINE=true \
  $HOME/.smartpark/lpr/bin/python -B scripts/lpr_service.py \
  --socket /tmp/lpr-eval.sock --warmup-image examples/plates/blue-01.jpg

# 逐图评测（结果 JSON 含逐图车牌、两阶段置信度、耗时与分组统计）
python3 eval_manifest.py --manifest examples/plates/manifest-provinces.csv \
  --out /tmp/lpr-benchmark-20261012.json --socket /tmp/lpr-eval.sock --root examples/plates
```
